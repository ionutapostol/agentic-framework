# Training: agentic-framework

A personal learning path for this framework, ordered by **learning sequence** — each
module assumes the previous ones. Work top to bottom; don't skim ahead until the current
module's self-check passes.

| # | Module | You'll learn | ~Time |
|---|--------|--------------|-------|
| 01 | [Framework mental model](01-framework-mental-model.md) | Agents vs skills vs routers; how the pieces find each other | 45 min |
| 02 | [Anatomy of an agent](02-anatomy-of-an-agent.md) | The agent file format end-to-end on a real example | 45 min |
| 03 | [Anatomy of a skill](03-anatomy-of-a-skill.md) | SKILL.md structure, references, validators, evals | 60 min |
| 04 | [Sprint pipeline & run contract](04-sprint-pipeline-and-run-contract.md) | The 4-phase pipeline and its safety rules | 60 min |
| 05 | [Routing & canonical rule homes](05-routing-and-canonical-rule-homes.md) | Where rules live and how discoverability survives growth | 45 min |
| 06 | [Build your own agent + skill](06-build-your-own-agent-and-skill.md) | Guided scaffold of a new workflow | 90 min |
| 07 | [Maintaining the framework](07-maintaining-the-framework.md) | Evolving rules without breaking the contract | 45 min |

**Total: ~6.5 hours** across focused sessions.

How to use each module: read Concepts → do the Code tour with the files open → do the
Exercises for real (don't just read them) → answer Self-check from memory, then verify.

This folder is gitignored. Write your own notes in `notes/` next to these files.
